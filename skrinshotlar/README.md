# Skrinshotlar — vaqtinchalik papka

Landing sahifasi uchun xom skrinshotlar shu yerga tashlanadi.

**Bu papka git'ga tushmaydi** (`.gitignore` da). Xom telefon skrinshoti
2–5 MB bo'ladi — repozitoriyga bunday fayllarni qo'shish uni shishiradi.
Optimallashtirilgan (WebP, ≤1600px) nusxalari `public/landing/` ga
joylanadi va faqat o'shalar commit qilinadi.

## Nomlash

Fayl nomi qaysi ekran ekanini bildirsin — men qaysi karta uchun
ishlatishni shundan bilaman:

```
dars-nazariya.png
flashcard.png
test-natija.png
kalkulyator-ipss.png
sertifikat.png
shifokor-panel.png
```

## Muhim ogohlantirish

⚠️ **Bemor ma'lumoti bo'lgan ekranni yubormang.** Bemorlar reestri,
tashrif kartasi, murojaatlar — bularda haqiqiy ism va telefon raqami
bo'ladi va ular ochiq landing sahifasiga, ya'ni butun internetga
chiqadi. Shu ekranlar kerak bo'lsa, avval soxta bemor kiritib,
keyin skrinshot oling.

## Talab

- Telefon skrinshoti afzal — sayt telefon-birinchi qilingan
- PNG yoki JPG — men o'zim WebP ga o'giraman
- Kesish/tahrirlash shart emas
